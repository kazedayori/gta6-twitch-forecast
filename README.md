Forecasts GTA VI's launch-day Twitch viewers hour by hour: given the viewer counts of the first hour of release day, it predicts each remaining hour as five quantiles, from the empirical distribution of comparable past launches' normalized trajectories, with a persistence fallback.

## Run it

```sh
python3 evaluate.py
```

`main.py` is the entrypoint: it reads a case from `/input/<id>.in` and writes `/output/<id>.out`. `evaluate.py` runs a leave-one-launch-out backtest against the house persistence baseline.
